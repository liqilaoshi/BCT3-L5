对话文本与分句朗读

点按声音图标可单独播放该句音频

主管

Wǒmen děi bǎ zhè fèn wénjiàn xiě hǎo.

我们得把这份文件写好。

We have to write this file.

助理

Shénme shíhou gěi kèhù?

什么时候给客户？

When should we give the file to the client?

主管

Xià zhōu yī qián yào bǎ wénjiàn fā gěi kèhù, yǒu kùnnan ma?

下周一前要把文件发给客户，有困难吗？

We need to send him the file by next Monday. Do you have any difficulty?

助理

Yīnggāi méi wèntí, nǐ xīngqīsān zài tíxǐng wǒ yíxià.

应该没问题，你星期三再提醒我一下。

That should be no problem. Remind me on Wednesday.

主管

Nǐ qīngchu kèhù de yāoqiú ma?

你清楚客户的要求吗？

Do you understand the client's requirements?

助理

Bié dānxīn, kèhù zěnme yāoqiú wǒmen zěnme zuò.

别担心，客户怎么要求我们怎么做。

Don't worry. We will do whatever the client requests.

生词学习 (Vocabulary)

根据教材标注整理的关键商务词汇

7 Words
得 děi
[aux.]

should; have to; must

例句：我们得把文件写好。

发 fā
[v.]

send out; issue; email

例句：把文件发给客户。

应该 yīnggāi
[aux.]

should; ought to; should be

例句：应该没问题。

再 zài
[adv.]

again; further; then

例句：你星期三再提醒我一下。

提醒 tíxǐng
[v.]

remind; warn; call attention to

例句：请提醒我一下。

要求 yāoqiú
[n./v.]

request; demand; requirement

例句：清楚客户的要求。

担心 dānxīn
[v.]

worry; be anxious; feel concerned

例句：别担心，没问题。
